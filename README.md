# Municipalidad de Santa Victoria Este

Sitio web institucional para la Municipalidad de Santa Victoria Este, Provincia de Salta, Argentina.

## Objetivo

Publicar una pagina institucional responsiva, optimizada para SEO y lista para desplegar en GitHub Pages.

## Estructura

```text
.
├── index.html
├── assets/
│   ├── icons/
│   ├── img/
│   └── logos/
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── robots.txt
├── sitemap.xml
├── .gitignore
└── README.md
```

## Desarrollo local

Abrir `index.html` directamente en el navegador o servir la carpeta con un servidor estatico.

## Publicacion en GitHub Pages

1. Crear un repositorio en GitHub.
2. Subir esta carpeta al repositorio.
3. En GitHub, ir a `Settings > Pages`.
4. Seleccionar la rama `main` y la carpeta `/root`.
5. Guardar la configuracion.
