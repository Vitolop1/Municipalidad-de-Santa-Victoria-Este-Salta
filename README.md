# Municipalidad de Santa Victoria Este

Sitio web institucional de la Municipalidad de Santa Victoria Este, Provincia de Salta, Argentina.

## Sitio publicado

https://vitolop1.github.io/Municipalidad-de-Santa-Victoria-Este-Salta/

## Contenido

- Portada institucional de la gestión municipal.
- Presentación fotográfica automática.
- Información de liderazgo y trayectoria de Rogelio Nerón.
- Obras, acciones territoriales y galería de gestión.
- Datos culturales, territoriales y canales de contacto.
